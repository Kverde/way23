# {{ $frontmatter.title }}

[Espanso](https://espanso.org) — это инструмент для автоматизации ввода текста с помощью клавиатуры. Например, вы хотите ввести формулу с нижним индексом. В Unicode есть символ `₁`, но ввести его стандартными средствами не получится. С Espanso всё проще: достаточно набрать определённый код, например `:sub1`, и он автоматически заменится на нужный символ.

Конфигурация Espanso основана на YAML-файлах. Отредактировать их можно с помощью команды:

```
espanso edit
```

Также файл можно открыть в любом текстовом редакторе.

Для быстрого поиска среди всех доступных команд используется сочетание клавиш `ALT+SPACE`.

Espanso поддерживает и более сложные сценарии. Например, по определённому коду можно вызвать всплывающее окно с выбором из заранее заданного списка вариантов. В конфигурации допускается использование переменных — например, текущей даты или времени. Описание настройки [находится в документации](https://espanso.org/docs/matches/basics/).

Помимо ручной настройки, доступны [готовые пакеты](https://hub.espanso.org/search) — уже собранные конфигурации для разных задач. Например, есть пакет для ввода [дробей из Unicode](https://hub.espanso.org/espanso-fractions) и даже [кодировщика Base64](https://hub.espanso.org/base64-encoder-decoder).
